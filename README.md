# 👥 HR Analytics Dashboard | Power BI

An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and provide actionable workforce insights. This dashboard enables HR professionals and business leaders to monitor key HR metrics, understand employee attrition, evaluate workforce demographics, and make data-driven decisions to improve organizational performance.

---

## 📌 Project Overview

The HR Analytics Dashboard transforms raw employee data into meaningful visual insights using Power BI. It helps organizations track employee performance, analyze attrition trends, monitor workforce diversity, and identify factors affecting employee retention through interactive reports and KPIs.

---

## ✨ Dashboard Features

- 👨‍💼 Total Employees
- 🚪 Employee Attrition Analysis
- 📉 Attrition Rate
- 💰 Average Salary
- 🎂 Employee Age Distribution
- 🏢 Department-wise Employee Analysis
- 🎓 Education Field Analysis
- 👥 Gender Diversity Insights
- 💼 Job Role Analysis
- ⭐ Job Satisfaction Analysis
- 📅 Years at Company Analysis
- 📈 Monthly Income Distribution
- 📊 Employee Performance KPIs
- 🎛️ Interactive Filters and Slicers

## 📂 Dataset

The dashboard is built using HR employee datasets containing:

- Employee Details
- Department Information
- Job Roles
- Education Fields
- Salary Data
- Attrition Status
- Age & Gender
- Job Satisfaction
- Years at Company
- Performance Ratings

The data was cleaned, transformed, and modeled in Power BI before creating the final dashboard.

---

## 📈 Key Insights

- Monitor overall employee count and workforce distribution.
- Analyze employee attrition across departments and job roles.
- Identify factors contributing to employee turnover.
- Compare salary trends and employee demographics.
- Evaluate job satisfaction across different employee groups.
- Track workforce diversity by gender, age, and education.
- Support HR decision-making with interactive visual reports.
